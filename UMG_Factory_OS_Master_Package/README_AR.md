# UMG Factory OS — النسخة الماستر

هذه الحزمة هي **النواة التنفيذية المحلية** للمشروع، مبنية لتكون نقطة الانطلاق الصحيحة للتطوير الفعلي.

## ما تحتويه الحزمة
- هيكل Flutter منظم Feature-First
- شاشات أساسية قابلة للعرض: Login / Register / Modules / Module placeholders
- Theme عربي بطابع Industrial Luxury
- نواة conflict governance: entities + services + controllers + draft manager
- وثائق تنفيذية عربية في مجلد docs/

## ما لا تدّعيه هذه الحزمة
- ليست التطبيق النهائي الكامل
- ليست ربطًا فعليًا مع السيرفر أو الذكاء الاصطناعي بعد
- لكنها **أفضل نواة قابلة للتوسعة** على نفس الرؤية التي تم بناؤها

## التشغيل
1. ثبّت Flutter
2. افتح المجلد
3. نفّذ:
   - `flutter pub get`
   - `flutter run`
