## رسائل مزامنة راقية
- تعذر الوصول إلى خادم الحوكمة المركزي. تم حفظ القرار محليًا، وسيواصل النظام المحاولة تلقائيًا فور استقرار الاتصال.
- تأخر الخادم في الاستجابة. القرار محفوظ، وسيُعاد الإرسال تلقائيًا وفق سياسة المزامنة دون الحاجة إلى إعادة الإدخال.
- تعذر إكمال المزامنة بسبب انتهاء الجلسة الحالية. يُرجى تجديد تسجيل الدخول لإتمام القرار.
- تم إيقاف المحاولات التلقائية لهذا القرار. نُقل السجل إلى المراجعة اليدوية حفاظًا على سلامة البيانات.
