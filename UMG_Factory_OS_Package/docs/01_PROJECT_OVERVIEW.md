# نظرة عامة على المشروع

UMG Factory OS هو نظام تشغيل وإدارة وسيطرة وتحليل صناعي للمصنع، يربط بين:
- المادة الخام
- التشغيل
- الإنتاج
- الجودة
- المخزون
- الصيانة
- الموارد البشرية
- الحسابات والمبيعات
- الحوكمة والمزامنة

## فكرة النظام
بدلاً من برامج منفصلة، يعمل النظام كمحرك مركزي يدير دورة المصنع بالكامل مع تتبع، حوكمة، سجلات، وأمان.

## الصناعات الأساسية المستهدفة
- خط GR للتنقيط
- PVC
- الخرازة
- الكسارة
- ماكينة حقن الفلاتر
