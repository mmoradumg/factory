# طبقة الأمان

- تشفير البيانات الحساسة محليًا
- تشفير أثناء النقل
- كلمات مرور Hash + Salt
- OTP آمن قصير العمر

- Device binding
- Audit Trail
- RBAC
- Least Privilege
- Local node + central sync

- محصنًا
- مشفرًا
- مراقبًا
- منضبطًا
