# Factory Audit System

Flutter starter project for:
- Audit dashboard
- Live audit feed
- Dio + interceptors
- Realtime websocket listener
- Local persistence layer
- Sync pipeline
- GetIt dependency injection
- Light/Dark theme

## Important
This environment did not include the Flutter SDK, so platform folders like `android/`, `ios/`, `web/`, `macos/`, `windows/`, and `linux/` were not generated here.

To make the project fully runnable on your machine:

```bash
flutter create .
flutter pub get
flutter run
```
